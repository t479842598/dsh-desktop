# 65abb3d91c65

## 症状

GitHub Actions upload-artifact 报 Artifact storage quota has been hit，构建成功但上传失败（macOS/Windows 两个 job 都挂在 Upload artifacts 步骤）

## 根因

免费账号 Actions artifact 存储配额 500MB 被账号下其他仓库（OpenCode2API 4.5GB、nol-browser-manager 2.8GB 等）的旧构建产物占满；配额用量 6-12 小时才重算，删除后不能立即恢复

## 修复动作

tag 发布改为各平台 job 用 softprops/action-gh-release 直接挂 Release assets（不走 artifact 存储）；workflow_dispatch 才用 upload-artifact；已批量删除旧 artifacts 释放 ~7.6GB

## 验证证据

新 workflow 在 v0.1.0 重建后 build 两 job 成功，Release assets 正常挂载
